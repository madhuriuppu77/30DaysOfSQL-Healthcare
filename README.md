# 30DaysOfSQL-Healthcare

This repository documents my 30-day SQL practice journey focused on mastering SQL through a self-created healthcare dataset.
All queries and exercises were built and executed using Microsoft SQL Server Management Studio (SSMS) to simulate real-world database scenarios.
The dataset represents a simplified healthcare environment including patients, doctors, visits, prescriptions, and billing tables — designed entirely from scratch for practical learning.

**Overview**
The goal of this project is to strengthen SQL skills from fundamentals to advanced concepts through daily structured practice.
Each day focuses on specific SQL topics applied to realistic healthcare-related use cases.
All SQL files are organized by day and topic for clarity.

Index creation and optimization basics
